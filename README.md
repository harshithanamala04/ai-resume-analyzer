### 1. Streamlit: 
Traditional web development requires HTML, CSS, and JavaScript.
Streamlit allows you to build beautiful, interactive frontend user interfaces (UIs) entirely in Python with just a few lines of code.

### 2. Google Gemini API (google-generativeai): 
This is the brain of the app. 
It reads the raw text, understands context, acts like a recruiter, and outputs structured analytical data.

### 3. Pandas: 
The industry standard for data manipulation in Python. 
We use it to instantly convert lists of skills generated by the AI into clean, organized, tabular structures that look highly professional on a dashboard.

### 4. PyPDF: 
LLMs cannot read a .pdf file directly; they can only read text strings.
PyPDF acts as the bridge that extracts raw text from a user's uploaded resume file.

### 5. Python-Dotenv:
Security best practice. 
It prevents you from hardcoding your private API keys into your code, which protects you from accidental leaks if you push your code to GitHub.
