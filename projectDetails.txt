1. Streamlit: 
Traditional web development requires HTML, CSS, and JavaScript.
Streamlit allows you to build beautiful, interactive frontend user interfaces (UIs) entirely in Python with just a few lines of code.

2. Google Gemini API (google-generativeai): 
This is the brain of the app. 
It reads the raw text, understands context, acts like a recruiter, and outputs structured analytical data.

3. Pandas: 
The industry standard for data manipulation in Python. 
We use it to instantly convert lists of skills generated by the AI into clean, organized, tabular structures that look highly professional on a dashboard.

4. PyPDF: 
LLMs cannot read a .pdf file directly; they can only read text strings.
PyPDF acts as the bridge that extracts raw text from a user's uploaded resume file.

5. Python-Dotenv:
Security best practice. 
It prevents you from hardcoding your private API keys into your code, which protects you from accidental leaks if you push your code to GitHub.

Steps for creating the project

1. After creation of project folder I'm setting up the Virtual Environment 
    why Virtual Environment means A virtual environment keeps this project's dependencies isolated so they don't clash with other Python projects on your machine.
    ( python -m venv venv )

2. Activating the Environment --> ( venv\Scripts\activate )

3. Creating the requirements file inside the folder as requirements.txt

4. Installing the libraries --> ( pip install -r requirements.txt )

5. Setting up the Environment because We need a secure place to store your Google Gemini API key. 
We use a .env file for this because it acts like a vault; your code can read it locally, but it keeps your key hidden from the public if you ever share your project.
    (i) creating .env file
    (ii) Add API Key variable in .env --> ( GEMINI_API_KEY=YOUR_ACTUAL_API_KEY_HERE )
    (iii) getting API key by using google AI studio. use the default gemini project and create an API key and paste in the .env file

6. Creating application file

7. running the stream lit server --> ( streamlit run app.py )

8. Connecting the AI engine layer (in app.py)

|| deploying the project ||

1. go to share.streamlit.io
2. Select Continue with GitHub to instantly link your repositories.
3. click on create app and then deploy a public app from github
4. Repository: Select newly created ai-resume-analyzer repository.
   Branch: Set this to main.
   Main file path: Type in app.py.
5. click Advanced settings....
A text area titled Secrets (TOML format) will appear. Paste API key configuration string right here:

Ini, TOML
